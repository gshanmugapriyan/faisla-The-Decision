# 📖 Problem Statement

Decision-making often involves evaluating multiple alternatives under uncertainty. People frequently rely on intuition or incomplete information, which can lead to inefficient or biased decisions.

The challenge is to build a platform that assists users in making structured, informed, and transparent decisions by combining interactive user input with intelligent analysis.

---

# 💡 Solution

**Faisla – The Decision** is an AI-powered web application designed to simplify complex decision-making.

The platform enables users to evaluate different choices through an interactive interface while leveraging intelligent analysis to provide meaningful recommendations and insights.

The project demonstrates full-stack web development, API integration, responsive UI design, and scalable application architecture.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/gshanmugapriyan/faisla-The-decision.git
```

Navigate into the project

```bash
cd faisla-The-decision
```

Install dependencies

Frontend

```bash
npm install
```

Backend

```bash
cd backend
npm install
```

Start Backend

```bash
npm start
```

Start Frontend

```bash
npm run dev
```
